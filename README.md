# Sayuru Bandara Portfolio

GitHub Pages-ready personal portfolio for Sayuru Bandara.

## Deploy
1. Upload all files to the repository root.
2. GitHub → Settings → Pages → Deploy from branch → `main` → `/ (root)`.
3. Add your custom domain under Pages → Custom domain.
4. Configure Cloudflare DNS for GitHub Pages.

The site is static HTML/CSS/JS and includes responsive mobile navigation, portfolio lightbox, CV download, contact links, and a Live Streaming section.
